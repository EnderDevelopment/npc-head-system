# NPC Head System

Create and manage NPCs with customizable heads and attack animations in FiveM.

## Features

- Create NPCs with customizable heads
- Players can attack NPCs with a button press
- NPC attack animations

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start npc_head_system` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

1. Configure the NPCs in the config.lua file.
2. Start your FiveM server.
3. Players can interact with the NPCs by pressing the configured button.

## Configuration

Configure the NPCs in the config.lua file. You can set the model, coordinates, heading, and whether the NPC should have a green head. You can also configure the attack animation and button.
